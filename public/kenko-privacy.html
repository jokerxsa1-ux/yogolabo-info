第2条（取得する情報）

当方は、次の情報を取得します。

  1. アクセス記録（体験版） — 体験版の Web サイトの配信に伴い記録される、IP アドレス、ブラウザの種類、アクセス日時、要求された URL
  2. ご意見（体験版・受付は終了） — 体験版の「ご意見を送る」機能（2026年11月15日に終了）で、利用者が「送る」を押した場合に送られた、次の情報
    • 満足度（★1〜5）、選んだ答え、ご意見の自由記述（300文字まで・任意）
    • 本ソフトウェアの版、使った画面の名前、使った時間（分）、ご意見の画面が表示されたきっかけ、自分のファイルを取り込んだかどうか
    • 回答の番号（その場で作る乱数。利用者を特定するものではありません）
    • 送信に伴う通信の記録（IP アドレス等）

    名簿、記録、取り込んだファイルの内容、氏名、メールアドレスは送られていません。
  3. 購入に関する情報 — 販売に利用する BASE（BASE株式会社）を通じて当方が確認する、購入者の氏名、メールアドレス、注文内容および注文日時。なお、クレジットカード番号等の決済情報は BASE が取り扱い、当方は取得しません
  4. お問い合わせの内容 — お問い合わせの際にいただくメールアドレス、氏名（記載がある場合）、およびお問い合わせの本文

第3条（児童生徒の情報について）

  1. 本ソフトウェアの製品版は、利用者が勤務する学校の児童生徒の出欠・健康観察の記録を扱います。これらの情報は利用者が指定する場所のファイルにのみ保存され、当方は取得しません。これらの情報の管理は、利用者が、勤務する学校および設置者の規程等に従って行うものです。
  2. 当方は、お問い合わせへの対応においても、実在する児童生徒の情報を含むファイル・画面の写真・記録を受け取りません。誤って送られた場合は、内容を確認せずに削除し、その旨をお知らせします。
  3. 体験版は架空のデータで動作します。体験版には、実在する児童生徒の情報を入力しないでください。

第4条（利用目的）

当方は、取得した情報を次の目的で利用します。

  1. 本ソフトウェアの提供、およびお問い合わせへの対応のため
  2. ご購入の確認、新しい版のご案内その他ご購入者への連絡のため
  3. 体験版の Web サイトの安定した配信、不正利用の防止および障害対応のため

第8条（安全管理措置）

当方は、取得した情報について、次の措置を講じています。
